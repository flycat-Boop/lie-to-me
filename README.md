## ✨ 核心玩法与特性 (Features)

*   **🎭 极致的拟真伪装**：伪造的企业级 Admin Panel、假的 `.env` 配置文件、逼真的 AWS 密钥与数据库密码，专钓“脚本小子”的贪婪。
*   **🏆 Steam 风格成就系统**：不再冷冰冰地拦截，而是触发【初出茅庐】、【单引号爱好者】等隐藏成就。
*   **🎬 楚门的世界 (The Truman Show)**：在终端输入 `truman` 或 `reality`，解锁专属彩蛋。你以为你在攻击真实世界，其实这场真人秀的观众都在看着你。
*   **🤝 病毒式“帮凶”传播**：被嘲讽后点击分享，会触发打字机特效，邀请你的朋友成为“共犯”。
*   **⚖️ 法治防线**：内置取证级 JSONL 日志与《网络安全法》警告，专治被激怒后试图越界的红队。
*   **🛡️ 严密的底层安全**：虽然前端在演戏，但后端我使用了 `flock` 文件锁、Web根目录隔离、防 XSS 转义，确保蜜罐自身绝不会被打崩。

## 🧠 核心理念：社工大于技术

传统的防御是“建墙”，而我的思路是“建假金库”。
利用黑客的虚荣心、好奇心和被嘲讽后的愤怒，消耗他们的时间，收集他们的 Payload。**最好的防御，就是像黑客一样欺骗他们。**

## 🚀 部署方式 (Quick Start)

无需复杂的配置，只需一个 PHP 环境：
1. 将 `index.php` 放入你的 Web 服务器目录（如 Nginx/Apache）。
2. 赋予目录写入权限（系统会自动在 Web 根目录外生成日志和封禁名单）。
3. 访问页面，开始你的“钓鱼执法”。

*(提示：建议在生产环境部署时，配置反向代理隐藏真实 IP。)*
